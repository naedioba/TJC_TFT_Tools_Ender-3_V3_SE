TJC TFT Tool 1.0 — Personnalisation de l'écran de l'Ender-3 V3 SE
                   Ender-3 V3 SE display customization
=====================================================================

FRANÇAIS
  1. Décompressez ce dossier où vous voulez.
  2. Double-cliquez sur « TJC TFT Tool.exe ». Aucune installation n'est nécessaire.
  3. Si Windows affiche « Windows a protégé votre ordinateur » (programme non signé) :
     cliquez sur « Informations complémentaires », puis « Exécuter quand même ».
  4. Le manuel complet s'ouvre avec le bouton « ? Aide » ou la touche F1.
  Conservez toujours une copie du fichier tjc.tft d'origine.

ENGLISH
  1. Unzip this folder anywhere.
  2. Double-click "TJC TFT Tool.exe". No installation is needed.
  3. If Windows shows "Windows protected your PC" (unsigned program):
     click "More info", then "Run anyway".
  4. The full manual opens with the "? Help" button or the F1 key.
  Always keep a copy of the original tjc.tft file.
