User manual — TJC TFT Tool

Overview

TJC TFT Tool lets you replace the images on the Ender-3 V3 SE display: boot screen, icons, backgrounds and labels. It extracts the 2,628 images in the tjc.tft file as PNGs, then rebuilds a file the display accepts, with its checksums recalculated.

The work takes four steps:

  1. Extract the images from the original file.
  2. Edit the ones you want to change.
  3. Rebuild a new tjc.tft.
  4. Check the file, then install it on the printer.

What the tool does not do: it does not change the screen layouts, the menus, the fonts or how the printer behaves. It only touches the images, and keeps their dimensions.

The tool is available in French and English, with a graphical interface and a command-line version.

Before you start

Always keep an untouched copy of the original tjc.tft file: it is your only way back to the Creality display. Rename it, for example, tjc_origine.tft and store a copy in a backup folder.

  • Always start from this original file. If you start from a file that was already modified, its earlier changes remain.
  • Never switch off the printer while the display is updating.
  • This software is not affiliated with Creality, TJC or Nextion. It comes without any warranty: you use it at your own risk.

Installation

Two versions are available: a ready-to-use Windows program (.exe), and a Python version for other systems or for changing the code.

Windows version (.exe) — recommended

No installation: unzip the archive and double-click TJC TFT Tool.exe. The manual is built into the program.

On first launch, Windows SmartScreen may show "Windows protected your PC", because the program is not digitally signed. Click More info, then Run anyway.

File Role
TJC TFT Tool.exe The complete program, with its manual
COPYING Full text of the GNU GPL v3 license, to keep with the software

Python version

  1. Download Python 3 from python.org and run the installer. Be sure to tick Add python.exe to PATH before clicking Install.
  2. Open the command prompt (Windows key, type cmd) and check the installation with python --version.
  3. Install the required libraries with python -m pip install pillow numpy.
  4. Put the program files in one folder, ideally with a short path, for example C:\ecran.
File Role
tjc_tft_gui.pyw Graphical interface: this is the file to launch
tjc_tft_tool.py The tool's engine, used by the interface or from the command line
aide\ This manual, in French and English
COPYING Full text of the GNU GPL v3 license, to keep with the software

On Windows, type python, not python3: the latter often opens the Microsoft Store instead of Python.

Getting to know the interface

Double-click TJC TFT Tool.exe (or tjc_tft_gui.pyw for the Python version) to open the interface; no console window appears.

Area Contents
Top right Help button and FR | EN language selector
Fields Original .tft file, images folder, output .tft file, each with a Browse… button
Main buttons Extract images, Rebuild .tft, Check a .tft
Below the buttons Open images folder, Clear log
Log Report of each operation: green when all is well, red on error
Bottom of the window Status bar, credits, About & credits button

The Help button (or the F1 key) opens this manual in your web browser, in the interface language.

The language selector switches the whole interface instantly, along with the log messages. Your choice is remembered for next time. On first launch, the interface uses the Windows language.

When you choose the original file, the interface suggests an images folder and an output\tjc.tft output file next to it. You can change them.

Step 1 — Extract the images

Extraction turns the original file into 2,628 PNG images in a few seconds.

  1. In Original .tft file, choose your tjc_origine.tft.
  2. In Images folder, keep the suggested folder or choose another one.
  3. Click Extract images. The log shows "2628 images extracted".
  4. Click Open images folder to browse them.

Each image is named number_widthxheight.png, for example 0000_240x320.png. The number identifies the image in the display; the dimensions are those it must keep. Image 0 is the boot screen.

If the folder already contains PNGs, the interface asks for confirmation: images with the same name will be overwritten.

Step 2 — Edit the images

Work in a separate folder, for example modifs, that contains only the images you change. All the others are taken unchanged from the original file.

  1. Copy the image to edit from the images folder to modifs.
  2. Open it in your image editor (GIMP, Paint.NET, Photopea, etc.).
  3. Edit it, then save it as PNG under exactly the same name.

Rules to follow:

  • Same dimensions. The display shows each image at a fixed position. An image of a different size is rejected.
  • PNG only. Never go through JPG: it adds invisible colour variations that make the image much heavier.
  • Same file name. The tool finds the image by the number at the start of its name.

Tips for staying within the available space:

  • Space for images is limited: about 14 KB of margin in the original file.
  • Flat colours, sharp shapes and text on a plain background compress very well.
  • Gradients, photos, soft shadows and blur compress poorly and take up a lot of space.
  • Image 0 (boot screen, 92 KB) is the heaviest: simplifying it frees a lot of space.

Good to know:

  • Many interface texts are images, one per language. To change an English label, edit the English image.
  • The display shows 65,536 colours (RGB565 format). Very fine gradients may show slight banding.

Step 3 — Rebuild the file

Rebuilding produces a new tjc.tft from the original file and your edited images.

  1. Original .tft file: your tjc_origine.tft.
  2. Images folder: the modifs folder.
  3. Output .tft file: for example output\tjc.tft. This file cannot have the same path as the original: the tool protects it.
  4. Click Rebuild .tft.

The log then shows a report:

Report line Meaning
Report for modified images Old and new size of each image, heaviest first
N image(s) replaced Numbers of the images actually changed
Remaining margin Space still available for further changes
File written Location of the new file
Header 1, Header 2, Resources, File CRC; file size Checksums verified by the display: all must read OK

An image identical to the original is not counted as modified: it is copied byte for byte.

Step 4 — Check and install on the printer

A file whose four CRCs and size all read OK is ready to install.

  1. Click Check a .tft. The tool checks the output file if it exists, otherwise the original file. The log should end with "File is consistent.".
  2. Copy the new tjc.tft to the SD card, following the display update procedure described by Creality for your version.
  3. With the printer off, insert the card, then switch the printer on.
  4. Wait for the update to finish without cutting the power.
  5. After the restart, check your images and browse the menus.

To return to the original display, install tjc_origine.tft the same way, renamed to tjc.tft.

Command-line use

Every feature of the interface is also available from the command line with the Python version, run from the program folder.

Command Effect
python tjc_tft_tool.py extract tjc_origine.tft images Extracts the images into the images folder
python tjc_tft_tool.py pack tjc_origine.tft modifs tjc.tft Rebuilds tjc.tft with the images in modifs
python tjc_tft_tool.py check tjc.tft Checks a file's checksums
python tjc_tft_tool.py version Shows the version, copyright and credits

Add --lang en or --lang fr anywhere in the command to choose the message language. By default, the system language is used.

If a path contains spaces, put it in quotes, for example "C:\My files\tjc_origine.tft".

Troubleshooting

Most errors come from the installation, a file path or an image that is too heavy.

Message or symptom Cause Fix
"Python was not found… Microsoft Store" On Windows, python3 points to the Store Type python instead of python3
"Cannot load tjc_tft_tool.py" at startup File missing from the folder, or libraries not installed Put both files together, then run python -m pip install pillow numpy
Double-clicking the .pyw does nothing Python not associated with .pyw files Reinstall Python with the PATH option, or run python tjc_tft_gui.pyw
The Help button reports a missing manual Python version: aide folder missing or moved Put the aide folder back next to tjc_tft_gui.pyw
"Windows protected your PC" The program is not digitally signed More info, then Run anyway
The antivirus blocks or deletes the .exe Common false positive for programs packaged with PyInstaller Allow the file in the antivirus, or use the Python version
The .exe takes a few seconds to open It unpacks itself in memory at startup Normal behaviour
FileNotFoundError The file is not in the current folder Use Browse…, or give the full path in quotes
"Wrong dimensions, nothing was written" Image resized while editing Restore the dimensions shown in its file name
"The modified images exceed the available space" Images too detailed: gradients, photo, saved through JPG Simplify the images at the top of the report, or lighten the boot screen
"This file is not a TJC T1-series .tft" File from another display or another model Use the Ender-3 V3 SE tjc.tft
A CRC line reads ERROR Damaged file, or changed by another tool Do not install it; rebuild from the original
Garbled accents in the console Windows command prompt encoding No effect on the files produced
Original margin larger than expected You are starting from an already modified file Start again from tjc_origine.tft

Frequently asked questions

Can I change the menus, the text the display generates, or the fonts?
No. The tool only replaces images of the same size. The pages, the display code and the fonts are kept as they are.

What if Creality releases a new display firmware?
Run the rebuild again with the new tjc.tft as the original file and your modifs folder. This works as long as the image numbers and dimensions have not changed; otherwise the tool lists the images concerned.

Why are some images not compressed?
The tool compresses an image only when that makes it smaller, exactly as TJC's own software does. Very detailed images are stored as is.

Can I edit many images at once?
Yes, all of them if you wish, as long as the total fits in the available space. Watch the "Remaining margin" line after each rebuild.

Are my colours preserved exactly?
Almost: the display uses 65,536 colours. The maximum difference is a few levels per channel, invisible to the eye in most cases.
