Manuel utilisateur — TJC TFT Tool

Présentation

TJC TFT Tool permet de remplacer les images de l'écran de l'Ender-3 V3 SE : écran de démarrage, icônes, fonds et libellés. Il extrait les 2 628 images du fichier tjc.tft en PNG, puis reconstruit un fichier que l'écran accepte, avec ses sommes de contrôle recalculées.

Le travail se fait en quatre étapes :

  1. Extraire les images du fichier d'origine.
  2. Modifier celles que vous voulez changer.
  3. Reconstruire un nouveau tjc.tft.
  4. Vérifier le fichier, puis l'installer sur l'imprimante.

Ce que l'outil ne fait pas : il ne modifie ni la disposition des écrans, ni les menus, ni les polices, ni le comportement de l'imprimante. Il ne touche qu'aux images, en conservant leurs dimensions.

L'outil est disponible en français et en anglais, avec une interface graphique et une version en ligne de commande.

Avant de commencer

Conservez toujours une copie intacte du fichier tjc.tft d'origine : c'est votre seul moyen de revenir à l'écran Creality. Renommez-le par exemple tjc_origine.tft et rangez-en une copie dans un dossier de sauvegarde.

  • Repartez toujours de ce fichier d'origine. Si vous partez d'un fichier déjà modifié, ses anciennes modifications restent.
  • Ne coupez jamais l'alimentation de l'imprimante pendant la mise à jour de l'écran.
  • Ce logiciel n'est affilié ni à Creality, ni à TJC, ni à Nextion. Il est fourni sans aucune garantie : vous l'utilisez sous votre responsabilité.

Installation

Deux versions existent : un programme Windows prêt à l'emploi (.exe), et une version Python pour les autres systèmes ou pour modifier le code.

Version Windows (.exe) — recommandée

Aucune installation : décompressez l'archive et double-cliquez sur TJC TFT Tool.exe. Le manuel est intégré au programme.

Au premier lancement, Windows SmartScreen peut afficher « Windows a protégé votre ordinateur », car le programme n'est pas signé numériquement. Cliquez sur Informations complémentaires, puis sur Exécuter quand même.

Fichier Rôle
TJC TFT Tool.exe Le programme complet, avec son manuel

Version Python

  1. Téléchargez Python 3 depuis python.org et lancez l'installeur. Cochez impérativement la case Add python.exe to PATH avant de cliquer sur Install.
  2. Ouvrez l'invite de commandes (touche Windows, tapez cmd) et vérifiez l'installation avec python --version.
  3. Installez les bibliothèques nécessaires avec python -m pip install pillow numpy.
  4. Placez les fichiers du logiciel dans un même dossier, de préférence au chemin court, par exemple C:\ecran.

Découvrir l'interface

Double-cliquez sur TJC TFT Tool.exe (ou sur tjc_tft_gui.pyw pour la version Python) pour ouvrir l'interface ; aucune fenêtre de console ne s'affiche.

Zone Contenu
En haut à droite Bouton Aide et sélecteur de langue FR | EN
Champs Fichier .tft d'origine, dossier des images, fichier .tft de sortie, chacun avec un bouton Parcourir…
Boutons principaux Extraire les images, Reconstruire le .tft, Vérifier un .tft
Sous les boutons Ouvrir le dossier des images, Effacer le journal
Journal Compte rendu de chaque opération : vert si tout va bien, rouge en cas d'erreur
Bas de la fenêtre Barre d'état, crédits, bouton À propos et crédits

Le bouton Aide (ou la touche F1) ouvre ce manuel dans votre navigateur, dans la langue de l'interface.

Le sélecteur de langue change toute l'interface instantanément, ainsi que les messages du journal. Votre choix est mémorisé pour les prochaines utilisations. Au premier lancement, l'interface prend la langue de Windows.

Quand vous choisissez le fichier d'origine, l'interface propose d'elle-même un dossier images et un fichier de sortie sortie\tjc.tft à côté de lui. Vous pouvez les modifier.

Étape 1 — Extraire les images

L'extraction transforme le fichier d'origine en 2 628 images PNG, en quelques secondes.

  1. Dans Fichier .tft d'origine, choisissez votre tjc_origine.tft.
  2. Dans Dossier des images, gardez le dossier proposé ou choisissez-en un autre.
  3. Cliquez sur Extraire les images. Le journal affiche « 2628 images extraites ».
  4. Cliquez sur Ouvrir le dossier des images pour les parcourir.

Chaque image porte un nom de la forme numéro_largeurxhauteur.png, par exemple 0000_240x320.png. Le numéro identifie l'image dans l'écran ; les dimensions sont celles qu'elle doit conserver. L'image 0 est l'écran de démarrage.

Si le dossier contient déjà des PNG, l'interface demande confirmation : les images de même nom seront écrasées.

Étape 2 — Modifier les images

Travaillez dans un dossier séparé, par exemple modifs, qui ne contient que les images que vous changez. Les autres seront reprises à l'identique depuis le fichier d'origine.

  1. Copiez l'image à modifier depuis le dossier images vers modifs.
  2. Ouvrez-la dans votre logiciel de retouche (GIMP, Paint.NET, Photopea, etc.).
  3. Modifiez-la, puis enregistrez-la au format PNG sous exactement le même nom.

Règles à respecter :

  • Mêmes dimensions. L'écran affiche chaque image à un emplacement fixe. Une image de taille différente est refusée.
  • Format PNG uniquement. Ne passez jamais par le JPG : il ajoute des variations de couleur invisibles qui alourdissent fortement l'image.
  • Même nom de fichier. L'outil retrouve l'image grâce au numéro au début du nom.

Conseils pour rester dans la place disponible :

  • La place pour les images est limitée : environ 14 Ko de marge dans le fichier d'origine.
  • Les aplats de couleur, les formes nettes et le texte sur fond uni se compressent très bien.
  • Les dégradés, les photos, les ombres douces et le flou se compressent mal et prennent beaucoup de place.
  • L'image 0 (écran de démarrage, 92 Ko) est la plus lourde : la simplifier libère beaucoup de place.

À savoir :

  • Beaucoup de textes de l'interface sont des images, une par langue. Pour changer un libellé en français, modifiez l'image française.
  • L'écran affiche 65 536 couleurs (format RGB565). Les dégradés très fins peuvent montrer de légères bandes.

Étape 3 — Reconstruire le fichier

La reconstruction produit un nouveau tjc.tft à partir du fichier d'origine et de vos images modifiées.

  1. Fichier .tft d'origine : votre tjc_origine.tft.
  2. Dossier des images : le dossier modifs.
  3. Fichier .tft de sortie : par exemple sortie\tjc.tft. Ce fichier ne peut pas avoir le même chemin que l'original : l'outil le protège.
  4. Cliquez sur Reconstruire le .tft.

Le journal affiche ensuite un rapport :

Ligne du rapport Signification
Bilan des images modifiées Ancienne et nouvelle taille de chaque image, de la plus lourde à la plus légère
N image(s) remplacée(s) Numéros des images réellement changées
Marge restante Place encore disponible pour d'autres modifications
Fichier écrit Emplacement du nouveau fichier
CRC en-tête 1, en-tête 2, ressources, fichier ; taille Sommes de contrôle vérifiées par l'écran : elles doivent toutes indiquer OK

Une image identique à l'originale n'est pas comptée comme modifiée : elle est recopiée octet pour octet.

Étape 4 — Vérifier et installer sur l'imprimante

Un fichier dont les quatre CRC et la taille indiquent OK est prêt à être installé.

  1. Cliquez sur Vérifier un .tft. L'outil contrôle le fichier de sortie s'il existe, sinon le fichier d'origine. Le journal doit se terminer par « Fichier cohérent. ».
  2. Copiez le nouveau tjc.tft sur la carte SD, en suivant la procédure de mise à jour de l'écran décrite par Creality pour votre version.
  3. Imprimante éteinte, insérez la carte, puis allumez l'imprimante.
  4. Attendez la fin de la mise à jour sans couper l'alimentation.
  5. Au redémarrage, vérifiez vos images et parcourez les menus.

Pour revenir à l'écran d'origine, installez tjc_origine.tft de la même façon, renommé en tjc.tft.

Utilisation en ligne de commande

Toutes les fonctions de l'interface existent aussi en ligne de commande, avec la version Python, depuis le dossier du logiciel.

Commande Effet
python tjc_tft_tool.py extract tjc_origine.tft images Extrait les images dans le dossier images
python tjc_tft_tool.py pack tjc_origine.tft modifs tjc.tft Reconstruit tjc.tft avec les images de modifs
python tjc_tft_tool.py check tjc.tft Vérifie les sommes de contrôle d'un fichier
python tjc_tft_tool.py version Affiche la version, le copyright et les crédits

Ajoutez --lang fr ou --lang en, n'importe où dans la commande, pour choisir la langue des messages. Par défaut, la langue du système est utilisée.

Si un chemin contient des espaces, mettez-le entre guillemets, par exemple "C:\Mes fichiers\tjc_origine.tft".

Questions fréquentes

Puis-je changer les menus, les textes saisis par l'écran ou les polices ?
Non. L'outil ne remplace que des images de même taille. Les pages, le code de l'écran et les polices sont repris tels quels.

Que faire quand Creality publie un nouveau firmware d'écran ?
Relancez la reconstruction avec le nouveau tjc.tft comme fichier d'origine et votre dossier modifs. Cela fonctionne tant que les numéros et dimensions des images n'ont pas changé ; sinon, l'outil signale les images concernées.

Pourquoi certaines images ne sont-elles pas compressées ?
L'outil compresse une image seulement si cela réduit sa taille, exactement comme le logiciel de TJC. Les images très détaillées sont stockées telles quelles.

Puis-je modifier beaucoup d'images à la fois ?
Oui, toutes si vous le souhaitez, tant que le total tient dans la place disponible. Surveillez la ligne « Marge restante » après chaque reconstruction.

Mes couleurs sont-elles exactement conservées ?
Presque : l'écran utilise 65 536 couleurs. L'écart maximal est de quelques niveaux par composante, invisible à l'œil dans la plupart des cas.
